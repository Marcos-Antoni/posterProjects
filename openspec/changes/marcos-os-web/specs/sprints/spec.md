## REMOVED Requirements

### Requirement: A Sprint Has A Name, A Date Range, And An Optional Goal
**Reason**: Sprints are retired from the product (Marcos OS R20): time-boxed iterations, velocity and story points are anti-patterns for a single user who needs one next step, not a cadence.
**Migration**: No replacement entity. Time framing moves to the Control 5-point plan deadline (`control-plan`) and the weekly priority (`reviews`). Legacy sprint data is only available in the Phase 1 backup (`legacy-data-export`).
